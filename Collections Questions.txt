1. K Closest Numbers
---------------------
- You are given an array of integers and a target value. Design a system to return K closest numbers to the target.
- Return k closest numbers
- If tie → prefer smaller number
- Output sorted in ascending order

Input:-
nums = [1, 4, 4, 6], K = 3, Target = 3
Output:-
[1, 4, 4]


Solution:-
--------
public class Main {
	public static void main(String[] args) {
		int[] arr = { 10, 4, 6, 7, 2, 21, 10, 1, 15 };
		int tar = 9;
		int k = 4;

		List<Integer> list = new ArrayList<Integer>();
		for (int i = 0; i < arr.length; i++) {
			list.add(arr[i]);
		}

		Collections.sort(list, (a, b) -> {
			int d1 = Math.abs(tar - a);
			int d2 = Math.abs(tar - b);
			if (d1 != d2) {
				return d1 - d2;
			}
			return a - b;
		});
		for (int i = 0; i < k; i++) {
			System.out.print(list.get(i) + " ");
		}
	}
}
Output:-
10 10 7 6
