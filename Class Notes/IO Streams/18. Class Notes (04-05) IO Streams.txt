File Class:-
===========
1. Introduction to File Class

- The "File Class" belongs to the java.io package.
- It is used to represent a file or directory (folder) in the system.
- It helps us to get information about files and directories.
- It also allows us to perform operations like:
	- Create file
	- Delete file
	- Check existence
	- Create directory

Note:- Creating a File object does NOT create a real file

Syntax:-
	File f = new File("abc.txt");


- This line only creates a reference (object).
- It does NOT create a file in the system.

Case 1: If file already exists
	- f will point to the existing file.

Case 2: If file does NOT exist
	- f will only represent the name/path, not a real file.

Creating a Physical File
-------------------------
	 - To actually create a file:

		- f.createNewFile();

- This method creates a real file in the system.
- If file already exists → it will NOT create a new one.

IO Streams:-
=-=-=-=-=-=
- An I/O Stream (Input/Output Stream) represents:
	- A source of input OR
	- A destination of output

"A stream is a flow of data from one place to another."

Flow of Data is:-
	- Program ↔ External Sources (files, devices, network, etc.)

Input Stream (Reading Data)
---------------------------
- Reading data INTO the program from external sources

Example Sources:
	- File
	- Keyboard
	- Network
	- Other programs

Example:-
- You are reading a file into your program
	- File → Program

Output Stream (Writing Data)
----------------------------
- Sending data FROM program to external sources

Example Destinations:
	- File
	- Screen
	- Printer
	- Network

Example
- You save data into a file
	- Program → File


Data Representation
-==-=-=-=-=-=--==-=
Computer understand Data in Binary form (0 and 1)

Java represent data in two forms:-
--------------------------------
1.Bytes (8-bit)
2. Characters (16-bit)

Types of IO Streams
===================
Based on data type, Java IO Streams are divided into:

1. Byte-Oriented Streams
=-=-=-=-=-=-=-=-=--==-=-=
Handle data in: Bytes (8-bit)

BYTE ORIENTED CLASSES
---------------------

Byte-oriented streams handle raw binary data in the form of bytes (8-bit).

Base Classes
- InputStream
- OutputStream

Used For
- Images
- Audio 
- Video 
- PDF
- Binary files

2. Character-Oriented Streams
=-=-=-=-=-=-=-=-=-==-=-=-=-=-=
Handle data in: Characters (16-bit)

 CHARACTER ORIENTED CLASSES
---------------------------

Character-oriented streams handle data in the form of characters (16-bit Unicode).

Base Classes
------------
- Reader
- Writer

Used For
--------
- Text files (.txt)
- Strings
- User input
- Logs


Byte vs Character Streams (Core Difference)
-------------------------------------------
Feature			Byte Stream		Character Stream
Data Type		Binary			Text
Unit			8-bit			16-bit
Base Class		InputStream		Reader
Use Case		Image, video		Text
Encoding Support	No			Yes


Byte Stream = Machine Language (raw data)
Character Stream = Human Language (readable text)

*IO Stream = Flow of data between program and external source*

FileWriter Class:-

FileWriter Constructors
-----------------------

- If file exists → overwrites data ❗

---------------
	FileWriter fw = new FileWriter("data.txt", true);

2. flush()
- Forces data to be written immediately to file
- Clears internal buffer

3. close()
- Closes the stream
- Releases system resources
- Automatically calls flush()

BufferedWriter Class:
=-=-=-=-=-=-=-=-=-=-=
- BufferedWriter class belongs to the java.io package.
- It is used to write character data into a file efficiently.
- It works with Character Streams.
- It uses a buffer to improve performance.
- BufferedWriter = Fast writing of text into files

Note:-- "This class can not connect with the file Directly, we need to provide a writer Class Object in constructor"


It is mainly used for:
---------------------
- Writing large text data
- Improving performance
- Writing data line by line
- Used with FileWriter

BufferedWriter Constructors
----------------------------
Using FileWriter
	- BufferedWriter bw = new BufferedWriter(new FileWriter("data.txt"));

Append mode
	- BufferedWriter bw = new BufferedWriter(new FileWriter("data.txt", true));


Methods of BufferedWriter Class
--------------------------------
1. write() method
- Used to write data into file

Overloaded methods:

write(int ch)
write(String str)
write(char[] ch)

2. newLine() 
- Adds a new line automatically
- No need to use \n manually

3. flush()
- Forces buffered data to be written to file
- Clears buffer

4. close()
- Closes the stream
- Releases resources
- Automatically calls flush()

Example code:-
------------

StreamTokenizer:-
=-=-=-=-=-=-=-=-=
- StreamTokenizer class belongs to the java.io package.
- It is used to break input data into small parts called tokens.
- It works with Character Streams.
- It can identify:
	- Words
	- Numbers
	- Symbols
- StreamTokenizer = Used for parsing text data token by token.
- Separating words and numbers
- Reading structured input data

What is a Token?
- A token is a small meaningful part of data.

Example:
Java 100 Python 200

Tokens are:
Java
100
Python
200

StreamTokenizer Constructor
--------------------------
- Using Reader object
	StreamTokenizer st = new StreamTokenizer(new FileReader("data.txt"));
Behavior:
- Reads character data from stream
- Breaks data into tokens automatically
- Detects words, numbers, and symbols

Types of Tokens
--------------
1. TT_WORD - Represents word token

Example:

Java
Hello
Student

2. TT_NUMBER - Represents numeric token

Example:

100
22.5
500

3. TT_EOF - Represents End Of File
- Used to stop reading loop

Special Character Tokens
Symbols are treated as separate tokens

Example:

+
-
*
/
@
#

Important Variables of StreamTokenizer
--------------------------------------
1. ttype - Stores type of current token

2. sval - Stores word value (String value)
- Used when:
	ttype == TT_WORD

3. nval - Stores number value (double value)
- Used when:
	ttype == TT_NUMBER

Important Methods of StreamTokenizer
------------------------------------
1. nextToken()
- Reads next token from stream
- Moves pointer to next token
- Returns token type

2. ordinaryChar(int ch)
- Makes character behave like normal symbol

3. wordChars(int low, int high)
- Defines custom word characters

4. whitespaceChars(int low, int high)
- Defines whitespace characters

Examples:-
=-=-=-=-=
1.
public class StreamTokenizerClassImpl {
	public static void main(String[] args){
		try(FileReader fr = new FileReader("xyz.txt")){ // Using try with resource
			StreamTokenizer st = new StreamTokenizer(fr);
			while(st.nextToken()!=StreamTokenizer.TT_EOF) {
				if(st.ttype==StreamTokenizer.TT_WORD) {
					System.out.println("Word :- "+st.sval);
				}else if(st.ttype == StreamTokenizer.TT_NUMBER) {
					System.out.println("Number :- "+st.nval);
				}else {
					System.out.println("Symbol :- "+(char)st.ttype);
				}
			}
		} catch (Exception e) {
			System.out.println(e);
		}
	}
}
Output:-
Word :- String
Number :- 100.0
Symbol :- #
Symbol :- $
Symbol :- @
Number :- 5.56
Word :- Krish

Inside file:-

public class StreamTokenizerClassImpl {
	public static void main(String[] args){
		try(FileReader fr = new FileReader("xyz.txt")){
			StreamTokenizer st = new StreamTokenizer(fr);
			st.wordChars(' ', ' ');
			st.wordChars('0', '9');
			st.whitespaceChars(',', ',');
			while(st.nextToken()!=StreamTokenizer.TT_EOF) {
				System.out.println(st.sval);
			}
		} catch (Exception e) {
			System.out.println(e);
		}
	}
}

Inside File:-

Important Points:-
- nextToken() always reads one token at a time.
- ttype stores current token type.
- sval works only for words.
- nval works only for numbers.

Serialization and Deserialization:-
=-=-=-=-=-=-=-=--==-=-=--=-=--=-=
- Serialization is the process of converting the state of an object into a byte stream.
- Deserialization is the reverse process of serialization.
- It converts byte stream back into the original Java object.

Important point:-
Serialization:
	- Object → Byte Stream

Deserialization:
	- Byte Stream → Object

Platform Independence:-
----------------------
- Serialization and deserialization are platform-independent.
- An object serialized on one platform can be deserialized on another platform.

Serializable Interface
----------------------
- To serialize an object, the class must implement:
	java.io.Serializable
- Serializable is a marker interface.
- Marker interface = interface without methods and fields.

Why Serializable Interface?
--------------------------
- It gives permission to JVM for serialization.
- Without Serializable interface, object cannot be serialized.
- If a class does NOT implement Serializable interface and we try to serialize its object, JVM throws:
	- NotSerializableException

Classes Already Serializable:-
----------------------------
- The following classes already implement Serializable internally:

	- Wrapper classes
	- String class
	- Most of the classes of Collection framework

ObjectOutputStream Class:-
=-=-=-=-=-=-=-=-=-=-=-=
- ObjectOutputStream class belongs to java.io package.
- It is used for serialization.
- It converts object into byte stream.
- It is mainly used for:
	- Saving objects into files

Method:-
------
- writeObject(Serializable obj) - Used to serialize object

Example Program (Serialization):-
-------------------------------
public class SerializationImpl {
	public static void main(String[] args) {
		try (FileOutputStream fos = new FileOutputStream("xyz.sr");
				ObjectOutputStream oos = new ObjectOutputStream(fos)) {
			A a = new A();
			a.x = 100;
			a.y = "String";
			String str = "name";
			Integer num = 200;
			
			oos.writeObject(a);
			oos.writeObject(str);
			oos.writeObject(num);
			
			System.out.println("Done....");
			
		} catch (Exception e) {
			// TODO: handle exception
		}
	}
}

public class A implements Serializable{
	int x;
	String y;
}

Output:-
Done...

Important Note:-
----------------
- Multiple objects can be serialized.
- During deserialization, objects must be read in the same order in which they were written.
- So, It is recommended to serialize objects of the same type into a single file.

ObjectInputStream Class
=-=-=-=-=-=-=-=-=-=-=-=
- ObjectInputStream class belongs to java.io package.
- It is used for deserialization.
- It converts byte stream back into Java object.
- It is mainly used for:
	- Reading serialized objects
	- Restoring saved object state

Method
-------
-Object readObject()
	- Reads serialized object
	- Returns Object type

Important Note:-
- readObject() returns Object class reference.
- Therefore downcasting is required.

Example Program (Deserialization):-

public class DeserializationImpl {
	public static void main(String[] args) {

		try (FileInputStream fis = new FileInputStream("xyz.sr"); 
				ObjectInputStream ois = new ObjectInputStream(fis);) {
			
			Object obj = ois.readObject();
			A a = (A)obj;
			System.out.println(a.x);
			System.out.println(a.y);

			String str = (String) ois.readObject();
			System.out.println(str);

			int num = (Integer) ois.readObject();
			System.out.println(num);

		} catch (Exception e) {
			System.out.println(e);
		}

	}
}

Output:-

100
String
name
200


transient Keyword:-
=-=-=-=-=-=-=-=-=-=
- transient keyword is applicable only for variables.
- transient variables do NOT participate in serialization.
- JVM ignores original value of transient variable.
- Default value is stored instead.
- It is mainly used for:
	- Security-related data
	- Temporary data

Example Program (transient):-
---------------------------
public class Student implements Serializable{
	String userName;
	transient String password;
}
public class SerializationImpl {
	public static void main(String[] args) {
		try (FileOutputStream fos = new FileOutputStream("xyz.sr");
				ObjectOutputStream oos = new ObjectOutputStream(fos)) {
			Student student = new Student();
			student.userName = "Krish";
			student.password = "krish@123";
			oos.writeObject(student);
			System.out.println("Done....");
			
		} catch (Exception e) {
			// TODO: handle exception
		}
	}
}
public class DeserializationImpl {
	public static void main(String[] args) {

		try (FileInputStream fis = new FileInputStream("xyz.sr"); 
				ObjectInputStream ois = new ObjectInputStream(fis);) {
			
			Object obj = ois.readObject();
			Student student = (Student)obj;
			System.out.println(student.userName);
			System.out.println(student.password);

		} catch (Exception e) {
			System.out.println(e);
		}

	}
}

Output:-
Krish
null

transient vs static
-------------------
- static variables are also not serialized.
- Because static variables belong to class, not object.

Object Graph:-
=-=-=-=-=-=-=
- Object graph means group of reachable objects.
- If one object references another object, all reachable objects are serialized automatically.

Important Rule:-
---------------
- Every object in object graph must be Serializable.
- Otherwise JVM throws:
	- NotSerializableException

Example (Object Graph):-
----------------------
public class Address implements Serializable{
	String state = "Punjab";
	String city = "Chandigarh";
	int pincode = 177023;
	@Override
	public String toString() {
		return "Address [state=" + state + ", city=" + city + ", pincode=" + pincode + "]";
	}
}

public class Student implements Serializable{
	String name;
	int roll;
	Address address;
	@Override
	public String toString() {
		return "Student [name=" + name + ", roll=" + roll + ", address=" + address + "]";
	}
	
}

public class SerializationImpl {
	public static void main(String[] args) {
		try (FileOutputStream fos = new FileOutputStream("xyz.sr");
				ObjectOutputStream oos = new ObjectOutputStream(fos)) {
			Student student = new Student();
			student.name = "Krish";
			student.roll = 22;
			student.address = new Address();
			oos.writeObject(student);
			System.out.println("Done....");
			
		} catch (Exception e) {
			System.out.println(e);
		}
	}
}

public class DeserializationImpl {
	public static void main(String[] args) {

		try (FileInputStream fis = new FileInputStream("xyz.sr"); 
				ObjectInputStream ois = new ObjectInputStream(fis);) {
			
			Object obj = ois.readObject();
			Student student = (Student)obj;
			System.out.println(student.name);
			System.out.println(student.roll);
			System.out.println(student.address);

		} catch (Exception e) {
			e.printStackTrace();
		}

	}
}

Output:-
Krish
22
Address [state=Punjab, city=Chandigarh, pincode=177023]


Serialization with Inheritance:-
=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=

Case 1:-
-------
- If parent class implements Serializable, child class automatically becomes Serializable.

Example:-
-------
class Animal implements Serializable {

}

class Dog extends Animal {

}

Dog class is automatically Serializable.

Case 2:
-------
- If parent class is NOT Serializable but child class implements Serializable:
- Child object can still be serialized.

Important Note:-
---------------
- Parent class instance variables are NOT serialized.
- During deserialization:
	- JVM executes parent class constructor
	- Default values from parent are restored

Example:-
public class A {
	int x;
}
public class B extends A implements Serializable{
	int y=200;
}
public class SerializationImpl {
	public static void main(String[] args) {
		try (FileOutputStream fos = new FileOutputStream("xyz.sr");
				ObjectOutputStream oos = new ObjectOutputStream(fos)) {
			B b = new B();
			b.x = 101;
			b.y = 201;
			
			oos.writeObject(b);
			System.out.println("done...");
			
		} catch (Exception e) {
			System.out.println(e);
		}
	}
}
public class DeserializationImpl {
	public static void main(String[] args) {

		try (FileInputStream fis = new FileInputStream("xyz.sr"); 
				ObjectInputStream ois = new ObjectInputStream(fis);) {
			Object obj = ois.readObject();
			B b = (B)obj;
			System.out.println(b.x);
			System.out.println(b.y);
		} catch (Exception e) {
			e.printStackTrace();
		}

	}
}

Output:-
0
201
